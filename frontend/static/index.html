Cómo funciona

  1. CargarSuba datos o elija un ejemplo.
  2. Revisar datosCorrija nodos, aristas, flota y parámetros.
  3. AnalizarElija un algoritmo y mírelo paso a paso sobre el grafo.
  4. EscenariosCierre nodos, cambie la flota, compare.
  5. ExportarInforme ejecutivo en Word/PDF, Excel y paquete para Grafos.
